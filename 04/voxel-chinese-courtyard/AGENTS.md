# 本项目的工作约定（人类与 agent 共同遵守）

体素中式古建群（Three.js）。以下规则是**完成定义**，不是建议；改动本仓库的任何 agent 都要照此执行。

## 1. 完成定义：`npm run selftest` 退出码必须为 0

- 该脚本走与渲染**完全同一条装配流水线**（`src/scene/assemble.js`），无需浏览器，约 0.5 秒。
- 任何"改完了"的声称都必须附 `commandsRun`，且其中包含 `npm run selftest` 与它的退出码；散文式断言不被接受。
- **禁止为了让测试变绿而放宽断言**。若某条断言在语义上不再成立，必须同时给出理由、把它改成更准确的陈述，并说明它现在能抓到什么。

## 2. 视觉改动必须过人眼

体素场景的问题通常截图才看得见（重檐被上檐遮住、铺装整片消失、树穿墙）。凡涉及几何/配色的改动，交付前至少复核一张全景 + 一张相关特写。

## 3. 中轴镜像不变量（`x = -0.5`）

- 中轴平面在 `x = -0.5`，镜像映射为 `x → -1-x`。
- 任何**按坐标取模的花纹**（瓦垄、彩画、斗拱、望柱、匾额字位、铺装错缝）都必须用**镜像不变量**做输入：
  横向用 `Math.abs(x + 0.5) | 0`，不要直接用 `x`。用 `x` 会让左右两半反相（中轴上不是同一条垄 / 望柱错位）。
- 有意为之的不对称（如东钟西鼓：两楼形制对称、楼内乐器不同）必须在 `scripts/selftest.mjs` 的 `INTENTIONAL` 里**登记理由并计数上报**，让豁免无法悄悄吞掉整块检查区域。

## 4. 判定的优先级（证据阶梯）

1. 先让不变量**在仓库内可机检**（加进 `npm run selftest`，最好是参数扫描而非单例）；
2. 再用命令测量；
3. 最后才谈静态复核/委派。

`src/voxel/VoxelBuilder.js` 的 `cullVerdict()` 是"不可见体素剔除"的唯一真源，自检调用的是同一个函数——不要在两处各写一份判定。

## 5. 性能不许靠感觉

帧时间用 `renderer.render()` 循环 + `readPixels` 同步实测（见 README「实际运行结果」），不要用后台窗口里 HUD 的 FPS 读数下结论——那个数会被浏览器节流。

## 6. 版本可审计（本仓库已 git init）

- 每次改动的报告里，除 `npm run selftest` 的退出码外，附 `git rev-parse --short HEAD` 与 `git status --porcelain`（应为空）。
- 提交信息写"为什么"，不写"改了哪些文件"（diff 已经说明了）。
- `node_modules/`、`dist/` 已被忽略；`dist/` 是可重建产物，不作为交付物追踪。
